# 历史样本评估（backtest）

## 适用意图

用户想了解历史公开研报在赛后的实际表现：

- "最近预测准不准" / "历史命中率" / "上个月表现如何" / "帮我复盘一下"。

## 参数识别（LLM 执行）

- 时间范围：用户说"最近"默认近 30 天；"上个月 / 上周"换算成具体日期区间；
- 关键词：球队名按 `match_query.md` 规则归一化；联赛名、标题关键词直接用；
- 用户未给筛选条件时，先用默认参数（近 30 天、每页 10 条）跑一版概览，再按用户反馈收窄。

## 执行步骤

1. 运行检索脚本：

```bash
python scripts/query_backtest.py --search <关键词> --date <YYYY-MM-DD> --per-page 10
```

   - 默认附带赛后结果与结算比对字段；用户明确不要时加 `--without-settlement`；
   - 样本较多时用 `--page` 翻页，直至取够或取完。

2. 汇总时明确交代：样本筛选条件、时间范围、样本量、缺失情况（多少场缺少赛后结果）。
3. 统计口径：
   - 只能称为"历史样本表现""一致率"或"观察比例"；
   - 禁止称为未来命中概率，禁止外推为未来结果。
4. 用户需要完整复盘报告时，加载 `templates/template_backtest.md` 按模板产出。

## 合规要求

- 历史样本仅用于复盘和方法评估；
- 输出结尾附来源声明（见 SKILL.md 公共约定）；
- 不提供投注建议。
