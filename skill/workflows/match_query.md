# 单场比赛数据查询（match_query）

## 适用意图

用户想了解某场具体比赛：赛前数据、双方情况、阵容、伤停、历史交锋、前瞻信息等。

典型输入："皇马这场怎么看"、"明天曼城比赛数据"、"阿森纳 vs 切尔西前瞻"、"帮我分析下周五国米那场"。

## 参数识别（LLM 执行，默认不追问）

用户不会知道 `fixture_id`，只会给出自然语言描述。你必须先自行解析：

### 1. 球队名归一化

用户可能输入简称、绰号、英文名甚至错别字。用你的足球知识映射到官方中文名：

- 绰号：红魔 → 曼联，枪手 → 阿森纳，蓝月亮 → 曼城，皇马 → 皇家马德里，巴萨 → 巴塞罗那，拜仁 → 拜仁慕尼黑，红军 → 利物浦，蓝军 → 切尔西
- 英文名：Arsenal → 阿森纳，Real Madrid → 皇家马德里，PSG → 巴黎圣日耳曼
- 简称：国米 → 国际米兰，马竞 → 马德里竞技，尤文 → 尤文图斯，ac米兰 → AC米兰

### 2. 日期解析

- 用户未给日期 → 默认北京时间今天；
- "明天 / 今晚 / 这周五 / 周末" → 换算成具体 `YYYY-MM-DD`；
- 用户明确给日期 → 直接使用。

### 3. 核心规则：同一支球队同一天只有一场比赛

因此定位到比赛后直接查询，**不要求用户确认**。让用户反复确认是糟糕的体验。

## 执行步骤

1. 运行 `python scripts/fetch_match.py --date <YYYY-MM-DD>`（不加 `--team`，拿全天候选列表）。
2. 在返回的 `fixtures` 中比对主客队名（用你归一化后的名称），选定 `fixture_id`。
   - 也可用 `--team <名称>` 预筛，但它是子串匹配，最终由你裁决。
3. 当日无该队比赛：自动再查前一天和后一天（各一次）。
   - 仍无 → 如实告知"前后三天均无该队赛程"，并列出当日实际有的比赛供参考，不得编造。
4. 运行 `python scripts/fetch_match.py --pack <fixture_id>` 获取 Match-Pack 全景数据。
5. 检查 `meta.source`：
   - `pipeline` 等物化来源通常字段更完整；
   - `realtime` 为实时组装回退，可能缺少预测首发、市场深度等字段，回复时需说明。
6. 输出时只使用实际返回的字段；缺失字段注明"当前接口未返回"，不得补造。

## 仅在以下情况才追问用户

- 用户未给出任何可定位的线索（如只说"今晚那场德比"，而当夜确有多场德比）；
- 追问时一次问全所需信息（哪支球队 + 哪一天），不要分多轮挤牙膏。

## 合规要求

- 区分事实、预测字段、衍生评分和模型判断；
- 不把预测首发、伤停影响评分、模型输出表述为确定事实；
- 不提供投注建议或结果保证。
