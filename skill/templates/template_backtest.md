# 模板：历史样本一致性评估

用于复盘历史公开记录与赛后结果的吻合程度。这份报告的价值在于**诚实**：样本怎么说就怎么写，它的说服力恰恰来自对局限的坦率披露。

## 一、分析方法论

### 1. 样本设计（动笔前必须先想清楚）

- **筛选条件要前置**：先定条件再看结果，严禁"看完成绩再挑样本"（幸存者偏差是这类报告最大的信任杀手）；
- **口径要写死**：时间范围、联赛范围、什么算"方向一致"、什么算"无法判定"，全部先定义再统计；
- **缺失要交代**：多少场没有赛后结果、为什么剔除，一个都不能藏着。

### 2. 样本量纪律

- 有效样本 < 20：只给明细和描述，**不下任何比例结论**，明确写"样本不足以支撑稳定结论"；
- 20-50：可以给比例，但必须标注"样本量有限，波动可能很大"；
- > 50：正常呈现，仍须注明这是历史观察而非规律。

### 3. 分组的价值

整体比例往往掩盖结构差异。至少尝试一个分组维度：按联赛 / 按主客场 / 按让球方向 / 按时间段。分组后任何一格样本 < 10，该格只列数字不解读。

### 4. 表述红线

- 只能说："历史样本一致率""观察比例""比分覆盖率"；
- 禁止说："命中率""胜率""爆冷率""稳"；
- 每个比例旁边必须能看到分母（"23/41，56.1%"而非孤零零的"56.1%"）。

## 二、标准结构

```markdown
# 历史样本一致性评估：{评估主题}

> 一句话摘要：{时间范围 + 样本量 + 最重要的一个发现}

## 一、样本设计

- 数据来源：球小策历史公开记录与赛后结果
- 时间范围：{开始} 至 {结束}
- 联赛范围：{范围及理由}
- 筛选条件：{客观、可复现的条件}
- 判定口径：{什么情况算"方向一致"/"不一致"/"无法判定"}
- 初始样本：{N} ｜ 有效样本：{N} ｜ 剔除/缺失：{N，说明原因}

## 二、总体表现

| 指标 | 结果 | 说明 |
|---|---|---|
| 方向一致率 | {n/N，百分比} | {口径备注} |
| 比分完全覆盖率 | {n/N，百分比} | {口径备注} |
| 无法判定占比 | {n/N，百分比} | {常见原因} |

样本量评估：{按上方纪律写明当前样本量能支撑什么级别的结论}

## 三、分组观察

| 分组 | 样本量 | 方向一致率 | 备注 |
|---|---:|---:|---|
| {联赛/主客场/方向} | {N} | {n/N} | {样本过小则标"不解读"} |

结构发现：{分组间是否有实质差异，还是整体波动的投影}

## 四、典型样本

- 一致案例：{1-2 个，说明当时记录与结果如何对应}
- 偏离案例：{1-2 个，诚实分析偏离原因：伤停变化/红牌/样本噪声}
- 偏离案例的分析价值高于一致案例，不得只挑好看的写

## 五、结论边界

**该样本能说明**：{历史范围内的有限结论}

**该样本不能说明**：{未来结果、单场确定性、条件外推}

**若用于当下比赛需先核对**：{阵容时效/赛程密度/数据覆盖变化}

---
数据来源：球小策足球数据服务（qiuxiaoce.com）。历史样本仅用于方法复盘与信息研究，不代表未来结果。
```

## 三、完稿自检清单

- [ ] 筛选条件是先定的、可复现的？
- [ ] 判定口径明确定义，"无法判定"单独成类？
- [ ] 每个比例都带分母？
- [ ] 样本量纪律已执行（<20 不下结论 / 分组 <10 不解读）？
- [ ] 偏离案例与一致案例都有呈现？
- [ ] 全文无"命中率/胜率/稳"类表述？
- [ ] 结论边界一节完整，明确"不能说明什么"？
