# 模板：社群赛事信息简报

适用于微信群 / QQ 群 / 社群每日推送。核心原则：**10 秒扫读**——用户在通勤路上用拇指滑着看，任何一行都不该需要停下来想。

## 一、创作方法论

### 1. 信息分层

- **第一屏必须看到**：今天几场、重点关注哪场、一个最有意思的数据点；
- 每场只给一条"看点"，看点=具体数据或具体待确认事项，不写"双方实力接近"这类废话；
- 简报不是文章，不展开论证，论证需求引导到研报或"回复场次名获取单场数据"。

### 2. 看点句式（一句话说清为什么值得看）

- 数据型："{主队}近 5 个主场 4 胜，{客队}客场已 3 场不胜"；
- 变量型："{球队}头号射手停赛，本赛季他参与了球队 40% 的进球"；
- 时间型："连续第 3 周一周双赛，{球队}体能是隐患"。

### 3. 排版纪律

- 用分隔线和留白分区，不用大段文字；
- 时间统一 24 小时制北京时间；
- 重要场次放前面，不按开球时间机械排序；
- 全文控制在手机两屏以内。

## 二、标准结构

```markdown
⚽ 球小策赛事简报 ｜ {M月D日 星期X}

今日共 {N} 场｜重点关注：{主队} vs {客队}（{开球时间}）

▎重点关注

{联赛} {开球时间}
{主队} vs {客队}
看点：{一条具体数据或变量}
数据状态：{完整 / 部分字段暂缺}

▎其余场次

{联赛} {开球时间}｜{主队} vs {客队}
{一句看点}

{联赛} {开球时间}｜{主队} vs {客队}
{一句看点}

▎赛前待确认

· {场次}：{首发/伤停/名单等待确认事项}

▎历史样本提示（如有引用）

· {筛选条件 + 样本量 + 观察结论}，仅为历史样本表现，不代表未来结果。

▎备注

数据查询时间：{HH:MM}
暂缺：{如实列出缺失，没有则写"无"}

————————
数据来源：球小策足球数据服务（qiuxiaoce.com）
内容仅供赛事信息研究，不代表确定结果
回复场次名可获取该场详细数据
```

## 三、变体

- **早间版**：全天赛程为主，看点从简，突出"今日共 N 场"；
- **临场版**（开赛前 2-3 小时）：只保留即将开球的场次，待确认事项提到最前，更新已确认首发（如有）；
- **晚报版**：加入当日已结束场次的比分速览 + 明日预告。

## 四、完稿自检清单

- [ ] 第一屏能看全"几场 + 重点场 + 一个数据点"？
- [ ] 每场看点都是具体数据/变量，无空话？
- [ ] 全文不超过手机两屏？
- [ ] 时间统一北京时间 24 小时制？
- [ ] 无投注引导、红黑榜、结果承诺？
- [ ] 缺失信息与查询时间已如实标注？
