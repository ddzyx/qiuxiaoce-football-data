# 模板：赛事信息短视频脚本

适用于抖音 / 视频号 / B站 / 快手等平台的 60 秒级赛事信息视频。目标是在合规前提下做到：**3 秒留人、全程高密度、结尾有互动**。

## 一、创作方法论

### 1. 选题钩子（决定 70% 的完播率）

开场必须用接口里的真实数据制造"信息缺口"，三选一：

- **数据反转型**："{主队}近 5 场只赢了 1 场，但有一项数据排在联赛前三。"
- **认知冲突型**："所有人都盯着{明星球员}，但真正决定这场走势的可能是{数据指向的环节}。"
- **悬念提问型**："{主队}主场{真实数据特征}，{客队}偏偏最怕这个——今晚会发生什么？"

红线：悬念必须能由数据兑现，禁止虚假悬念、恐吓式标题、贬损球队或球员。

### 2. 节奏控制

- 每 10-15 秒必须抛出一个新信息点，观众的注意力以 15 秒为单位流失；
- 单句口播不超过 25 个字，数字要"说人话"："场均预期进球 1.83 个"→"每场能创造出接近两个进球的机会"；
- 全片只讲 **1 条主线**，数据点服务于主线，不是数据堆砌。常见主线：
  - 矛与盾：{主队强项} vs {客队弱项}，数据一一对应；
  - 变量：{伤停/轮换}如何改变两队对比；
  - 反差：排名/名气接近，但过程数据差距大。

### 3. 可信度建设（短视频最稀缺的）

- 每个数字带口径："近 5 场""本赛季主场"，口径就是专业感；
- 预测类信息主动标注"这是预测""赛前还要确认"，反而提升信任；
- 结尾坦诚列出 1-2 个"目前还不知道的事"，比假装全知更有说服力。

## 二、标准结构（60 秒版）

```markdown
# 短视频脚本：《{标题——含钩子，15 字以内}》

**主线**：{一句话说明本片逻辑主线}
**建议时长**：55-65 秒 ｜ **语速**：每分钟 220-240 字
**画面基调**：对阵卡 → 数据动效 → 球员/战术画面 → 数据对比图

## 0:00-0:03 钩子
- 口播："{钩子句，必须是真实数据支撑的反差或问题}"
- 画面：对阵卡 + 开球时间，钩子关键词做大字弹出
- 字幕：钩子句全文上屏

## 0:03-0:15 背景快进
- 口播："{双方近况各一句，只挑与主线相关的数据}"
- 画面：近 5 场战绩条、排名对比卡
- 要点：不全面罗列，只给主线需要的背景

## 0:15-0:35 核心论证（本片主体）
- 口播："{围绕主线展开 2-3 个数据点，每个数据点=数据+一句解释}"
- 画面：每个数据点配一张对比图/战术示意，数字放大动画
- 要点：数据之间要有逻辑连接词——"所以""但问题是""更关键的是"

## 0:35-0:48 变量与不确定性
- 口播："{伤停/预测首发/临场变量，明确标注哪些是预测}"
- 画面：伤停名单卡、待确认图标
- 要点：这一段是合规与可信度的关键，不可省略

## 0:48-0:58 收口与互动
- 口播："赛前重点确认{1-2 件事}。你觉得{开放性问题}？评论区聊聊。"
- 画面：三件事清单卡 + 关注引导
- 要点：互动问题要具体可答，不问"你觉得谁会赢"这种站队问题

## 配套文案
- **视频标题**：{钩子压缩版，带球队名，利于搜索}
- **发布文案**：{2-3 句，复述核心看点 + 互动问题 + 数据来源}
- **话题标签**：#{联赛} #{主队} #{客队} #赛事前瞻 #足球数据

---
数据来源：球小策足球数据服务（qiuxiaoce.com）。视频内容仅供赛事信息研究，不代表确定结果。
```

## 三、平台适配

- **抖音/快手**：钩子最激进（反差型优先），前 3 秒必须出球队名；竖屏 9:16，字幕字号大；
- **视频号**：受众偏成熟，认知冲突型钩子更稳；发布文案可稍长；
- **B站**：可放宽到 90-120 秒，论证段增加 1-2 个数据点，标题可带【数据前瞻】前缀。

## 四、完稿自检清单

- [ ] 前 3 秒有真实数据支撑的钩子？
- [ ] 每个数字都来自接口返回且带统计口径？
- [ ] 全片只有一条主线，无关数据已删除？
- [ ] 预测字段已标注"预测"，待确认事项已列出？
- [ ] 无投注引导、无结果保证、无贬损表述？
- [ ] 互动问题具体可答、非站队式？
- [ ] 数据来源声明已附？
